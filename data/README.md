# Data

The data files are **not committed** to this public repository (see `docs/DECISIONS.md`, D-003). They are distributed to enrolled students by the course instructor (Moodle, *Aprendizagem Automática 2026/27*). The original data comes from the Kaggle competition [PetFinder.my Adoption Prediction](https://www.kaggle.com/c/petfinder-adoption-prediction/data).

## Setup

Place the four files supplied by the professor, **unchanged**, in `data/raw/`:

```text
data/
├── raw/                       ← original files, never edited (git-ignored)
│   ├── PetFinder_dataset.csv  (~6.6 MB, 14,993 listings)
│   ├── breed_labels.csv       (307 breeds)
│   ├── color_labels.csv       (7 colours)
│   └── state_labels.csv       (15 states)
└── processed/                 ← files generated by the notebook (git-ignored)
```

## Rules

- **Never edit files in `raw/`.** All cleaning happens in code.
- Anything in `processed/` must be reproducible by running the notebook.
- The main CSV needs a custom loader; see `docs/DATA_DICTIONARY.md` §4.
