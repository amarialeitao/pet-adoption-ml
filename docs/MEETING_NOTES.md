Newest meeting first. Copy the template for each meeting.

```markdown

**Present:** …

### Agenda
1. …

### Discussion
- …

### Decisions
- (also add to DECISIONS.md)

### Action items
- [ ] @github-user — task (issue #…) — due YYYY-MM-DD
```

## Suggested agenda for the kick-off meeting

1. Introductions; add everyone's name and GitHub handle to the README.
2. Register the group on Moodle and note the group number (`nn`).
3. Decide: scikit-learn only, Orange3, or both.
4. Review the open questions in `DATA_DICTIONARY.md` §5 and decide who asks the professor.
5. Split M1 / M2 issues and self-assign on the project board.
6. Agree on the branching / review workflow and a weekly meeting slot.
